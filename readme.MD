# Codebase Analysis – AI-Powered Code Debugger and Explainer

> **Abstract** : This project is a web-based application that uses artificial intelligence to analyze and debug source code submitted by users. Designed to simulate the thought process of an experienced software developer, the system not only identifies bugs or issues in the code but also provides detailed explanations and step-by-step reasoning behind each solution. It breaks down complex logic, highlights inefficient structures, and suggests optimized alternatives. This tool is particularly useful for novice programmers trying to understand code behavior, as well as experienced developers who want to speed up the debugging process. The application supports multiple programming languages and aims to bridge the gap between coding and comprehension by offering immediate, insightful feedback. Its educational value makes it a powerful assistant in coding environments, bootcamps, and collaborative development settings.

### Deployment Steps
Please follow the below steps to run this project.
1. python -m venv myvenv
2. activate myvenv
3. pip install -r requirements.txt
4. cd backend
5. uvicorn main:app --host 0.0.0.0 --port 8000 --reload

6. open another terminal
7. cd frontend
8. npm install
9. npm run dev
